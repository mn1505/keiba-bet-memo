# 競馬の買い目メモアプリ

競馬で購入予定または購入済みの買い目を記録できる、シンプルなローカルWebアプリです。

HTML、CSS、JavaScriptだけで作っているため、フレームワークやビルド作業は不要です。登録した内容はブラウザの `localStorage` に保存されるので、ブラウザを閉じても同じブラウザであればデータが残ります。

## 使い方

1. `index.html` をブラウザで開きます。
2. 日付、競馬場、レース番号またはレース名を入力します。
3. 券種を選び、買い目と金額を入力します。
4. 必要であればメモを入力します。
5. 「登録する」ボタンを押すと、一覧に買い目が追加されます。
6. 不要な買い目は「削除」ボタンで削除できます。
7. 一覧の上部に合計購入金額が表示されます。

## ファイル構成

- `index.html`：画面の構造を作るファイルです。
- `style.css`：見た目やスマホ対応のレイアウトを設定するファイルです。
- `script.js`：登録、一覧表示、削除、合計金額計算、保存処理を行うファイルです。
- `manifest.json`：Androidのホーム画面に追加するときのアプリ名やアイコンを設定するファイルです。
- `service-worker.js`：一度開いたファイルをキャッシュして、PWAとして動かすためのファイルです。
- `icons/icon.svg`：ホーム画面やブラウザで使うアプリアイコンです。
- `README.md`：アプリの概要や使い方をまとめた説明ファイルです。

## Android Chromeでホーム画面に追加する方法

Android ChromeでPWAとして追加するには、HTTPSのURLで開く必要があります。`index.html` を直接開く方法では、通常のWebページとしては使えますが、ホーム画面追加やオフライン用の仕組みが正しく動かない場合があります。

GitHub Pages、Netlify、Vercelなどにこのフォルダの中身を公開すると、HTTPSで開けるためAndroid Chromeから追加しやすくなります。

HTTPSで公開したページをAndroid Chromeで開いたら、Chrome右上のメニューから「ホーム画面に追加」を選びます。追加名は「買い目メモ」と表示されます。

登録した買い目はこれまで通りブラウザの `localStorage` に保存されます。ホーム画面から開いた場合も、同じChrome内のデータとして保存されます。

パソコンで表示を確認するだけなら、このフォルダで簡易サーバーを起動できます。`http://localhost` は開発用として扱われるため、同じパソコンのChromeではPWAの動作確認にも使えます。

```bash
python3 -m http.server 8000
```

同じパソコンで確認する場合は、Chromeで次のURLを開きます。

```text
http://localhost:8000
```

Androidスマホで同じWi-Fi内のパソコンにアクセスする場合、次のようなURLでも画面表示は確認できます。ただしHTTP接続のため、PWAのインストール確認にはHTTPS公開したURLを使ってください。

```text
http://パソコンのIPアドレス:8000
```

## 今後追加できそうな機能

- 的中・不的中の記録
- 払戻金の入力と収支計算
- 競馬場や券種での絞り込み
- 日付順や金額順での並び替え
- CSVでの書き出し
- 全データ削除ボタン

## ローカルでの開き方

このアプリはサーバーを起動しなくても使えます。

1. このフォルダを開きます。
2. `index.html` をダブルクリックします。
3. ブラウザでアプリが表示されます。

データは開いたブラウザの `localStorage` に保存されます。別のブラウザや別の端末では同じデータは表示されません。
